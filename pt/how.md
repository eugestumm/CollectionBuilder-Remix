# Como usar este projeto

Este arquivo digital oferece múltiplas visualizações dos metadados anotados. Abaixo, você encontra instruções sobre como utilizar cada uma dessas ferramentas.

* **Bajubá**
  * **Explorar Léxico**: Esta seção contém uma lista de hiperlinks com todas as palavras utilizadas em Pajubá em ordem alfabética. A frequência determina seu tamanho (por exemplo, palavras maiores indicam que são mais frequentes, palavras menores indicam que são menos frequentes). Clicar na palavra selecionada direcionará você para uma lista de todas as obras que utilizam essa palavra.
  * **Glossário**: Esta seção oferece uma amostra lexical em Pajubá juntamente com sua contraparte em inglês.
* **Visualização**:
  * **Gráfico de Rede por Obra**: Este gráfico cria uma visualização em rede do léxico utilizado por cada obra. Ele mostra quais palavras são comuns a diferentes produções culturais e como elas se conectam entre si.
  * **Linha do Tempo da Documentação do Pajubá**: Este gráfico cria uma visualização temporal do léxico utilizado por cada obra, mostrando se ela aparece na mídia de massa.
* **Explorar**: Esta seção permite que você veja todas as produções culturais catalogadas por este arquivo digital. Conta com uma barra de pesquisa onde você pode buscar metadados como léxico, título, autor, local, licença e tipo de obra.
* **Etiquetas**
  * **Categorias**: Esta seção lista o gênero de todas as obras presentes neste arquivo digital.
  * **Localizações**: Esta seção cria tags de todas as cidades nas quais as obras foram publicadas.
* **Mapa**: Esta seção apresenta uma visualização em mapa digital de todas as produções culturais catalogadas pelo projeto.
* **Cronologia**: Esta seção exibe uma linha do tempo cronológica da publicação das obras.
